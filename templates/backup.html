📤 Restore from Backup Danger Zone · Admin Only

Upload a previously downloaded backup file to restore data. Supports both JSON and Excel (.xlsx) backup files. Choose Merge to add missing records without touching existing ones, or Full Replace to wipe documents and reload everything fresh.

⚠️

Full Replace permanently deletes all current documents and routing slips before restoring. Users are never deleted for safety. Always download a fresh backup before doing a Full Replace.

🛑

Read before restoring. Merge mode is safe — it only adds records that don't already exist and never overwrites what's there. Use it for most restores. Full Replace is destructive — it wipes and overwrites all current documents and routing slips before reloading from the file, and cannot be undone. Only use it to roll the whole database back to a known-good state, and always download a fresh backup first.
