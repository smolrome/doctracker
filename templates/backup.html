The JSON backup is the real backup — it captures every table and field (documents including trash, users, routing slips, offices, and document timelines) and is the file you upload under Restore to rebuild LAKAD.
The Excel file is a flattened, printable report (6 sheets: Summary, Documents, Routing Slips, Users, Offices, Trash) for sharing with management — it cannot be used to restore (it drops document timelines and routing, and renumbers records).
Download the JSON weekly (and before any major change) and store dated copies safely — PC, USB drive, or Google Drive. If the database ever resets, the JSON backup restores everything in seconds.

Click to choose your .json backup file

Read before restoring. Merge mode is safe — it only adds records that don't already exist and never overwrites what's there. Use it for most restores. Full Replace is destructive — it wipes and overwrites all current documents and routing slips before reloading from the file, and cannot be undone. Only use it to roll the whole database back to a known-good state, and always download a fresh backup first.
